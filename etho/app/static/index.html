Behavior definitions

One definition per behavior, as you would write it in a methods section. The defaults are the CalMS21 resident-intruder definitions (Segalin et al., MARS, eLife 2021).

Your video frames are sent to Meta's Model API (Standard mode, not the data-contributor mode) for tracking and rule writing, and to Fireworks (Muse Spark Open) for tier-1 checks. Detector code runs in a local sandbox. The app estimates the cost before starting and refuses a job that would pass its daily spend cap.
