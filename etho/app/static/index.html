Privacy notice. Uploads are processed by Meta's Model API in Standard mode. Meta states that it "does not use your Content from Standard Services to train Meta Models" and keeps API content as described in its Terms and Privacy Policy (Meta Model API Data Commitments). Frame strips from your video are sent to Fireworks (Muse Spark Open) for the tier-1 checks; Fireworks and Meta keep request logs under their own policies. Within about 24 hours after upload, the video, its results and every intermediate file made from it are deleted from this server. The clips uploaded to Meta's Files API for tracking are deleted there through its API right after tracking, again when the job ends, and again at that deadline if an attempt failed. Kept longer: detector code written from your behavior definitions (no video or user data; it is reused when someone writes the same definition), the spend ledger (job id, times, token counts, cost, and the phrase used to find the animals), and server logs that include job links. Revising a showcase also uses the Standard models. Only upload video you have the right to share. Detector code runs in a local sandbox. The app estimates the cost before starting and refuses a job that would pass its spend cap.
