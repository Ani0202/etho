Found seven issues. References below use the patch’s line numbers.

1. **P1 — Reservations do not bound actual cost.** [gateway.py:137](/home/ubuntu/work/etho/etho/gateway/gateway.py:137)  
   The estimate counts only messages/input, omitting billable fields such as tool definitions and Responses `instructions`. Videos receive a fixed estimate regardless of duration. Reproduction: adding a 300,000-character tool description left the reservation unchanged at `$0.00010875`. Negative `max_tokens` also produced a negative reservation. The ledger lock cannot prevent overspending with these estimates.  
   **Fix:** validate positive token/frame limits and finite, nonnegative reservations; calculate a conservative bound from the complete outgoing request and validated media limits. Add tests near the cap with large tools, video, and invalid limits.

2. **P1 — Ambiguous failures can double-bill while losing spend accounting.** [gateway.py:201](/home/ubuntu/work/etho/etho/gateway/gateway.py:201), [gateway.py:273](/home/ubuntu/work/etho/etho/gateway/gateway.py:273)  
   Every `TransportError`, including a read timeout after generation may have completed, retries the POST without an idempotency key. Only the final success is charged; exhausted retries are booked at `$0`. A malformed HTTP 200 JSON response also releases its reservation at `$0`. Mock reproductions confirmed both behaviors.  
   **Fix:** distinguish failures known to precede submission from ambiguous outcomes. Use provider-supported idempotency or reconciliation; retain conservative charges for unresolved attempts. Test read timeouts after acceptance, retry exhaustion, and truncated successful responses.

3. **P1 — Expired reservations silently erase potentially incurred spend.** [ledger.py:74](/home/ubuntu/work/etho/etho/gateway/ledger.py:74)  
   After two hours, `_inflight()` deletes a reservation without recording a charge or checking completion. A worker crash after provider acceptance therefore restores budget for money potentially already spent. A sufficiently long active stream can also lose its reservation.  
   **Fix:** retain uncertain reservations or settle them conservatively until reconciled. Track active calls separately from abandoned calls. Add crash-recovery and expiry tests.

4. **P1 — Concurrent identical requests bypass cache deduplication and collide on temporary files.** [gateway.py:263](/home/ubuntu/work/etho/etho/gateway/gateway.py:263), [gateway.py:366](/home/ubuntu/work/etho/etho/gateway/gateway.py:366)  
   Cache lookup and provider execution have no per-key lock. Two synchronized identical misses produced two paid POSTs. Concurrent SAM calls also write the same `.partial` file; JSON writers in one process share the PID-based temporary filename in [cache.py:44](/home/ubuntu/work/etho/etho/gateway/cache.py:44). These collisions can corrupt output or fail a rename after billing.  
   **Fix:** lock each request key across lookup, execution, and publication; recheck after acquiring the lock and use unique temporary files. Add concurrent LLM and SAM tests.

5. **P1 — Truncated SAM streams are cached as successful results.** [gateway.py:435](/home/ubuntu/work/etho/etho/gateway/gateway.py:435)  
   EOF or `[DONE]` ends consumption without requiring `response.completed`. A mock stream containing only a partial mask delta returned successfully; `sam()` then publishes and caches that incomplete output. Subsequent runs reuse damaged tracking results.  
   **Fix:** require a successful terminal event before publishing output. Treat premature termination as an uncertain billed failure and discard partial results. Test clean EOF, `[DONE]`, and explicit failure without completion.

6. **P2 — SAM CLI omits required FPS subsampling.** [cli.py:95](/home/ubuntu/work/etho/etho/gateway/cli.py:95)  
   The CLI counts and uploads the original video without inspecting or reducing its FPS. Ordinary 30/60 FPS inputs therefore bypass CLAUDE.md’s 10–15 FPS default.  
   **Fix:** subsample before hashing/uploading and count the resulting frames, with an explicit override for justified full-rate runs. Test using a high-FPS input.

7. **P2 — SAM CLI loads the entire decompressed output into memory.** [cli.py:99](/home/ubuntu/work/etho/etho/gateway/cli.py:99)  
   `list(res.lines())` retains every frame’s raw mask text; `"\n".join(lines)` creates another large allocation. This defeats streaming and can exhaust memory on long videos.  
   **Fix:** count lines incrementally and stream directly to `--out`. Add an iterator-based regression test.
